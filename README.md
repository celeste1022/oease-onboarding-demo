# O' ease · Onboarding Demo

[打开在线 Demo](https://celeste1022.github.io/oease-onboarding-demo/)

O' ease 的可点击 Onboarding 演示，支持手机及桌面浏览器。

## 体验内容

- 沉浸式欢迎页：A moment to reconnect。
- 协议确认弹窗，可直接同意并继续。
- 新邮箱注册、密码登录、邮箱验证码登录。
- 六位验证码、60 秒重发倒计时及异常提示。
- 设置及重置密码：8–20 位，字母、数字、符号，二次确认及校验图标。
- 模拟收件箱及可选择的失败场景。

## 演示账号

- 邮箱：`hello@oease.demo`
- 密码：`Ease@2026`
- 验证码：`123456`

本项目为前端演示，账号只在页面会话内模拟。不发送真实邮件，不连接第三方账号或硬件。请勿使用真实密码。

## 本地打开

直接打开 `index.html`，或执行 `python3 -m http.server 4173` 后访问 `http://localhost:4173`。

## 发布

GitHub Pages 从 `main` 分支根目录发布。更新并推送这三个静态文件后，页面会自动更新。
